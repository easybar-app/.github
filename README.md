# EasyBar organization profile

This special repository contains the public profile for the
[`easybar-app`](https://github.com/easybar-app) GitHub organization.

The organization overview is rendered from [`profile/README.md`](profile/README.md).

## Updating the profile

Keep the profile concise and direct visitors to [easybar.dev](https://easybar.dev) for detailed
documentation. Repository names, installation commands, and contribution links should remain in
sync with the EasyBar repositories.
